# fe-pattern

A static gallery of 89 modern frontend patterns (post-2023) meant to be copied and pasted.
Every pattern is vanilla HTML/CSS/JS under `patterns/<id>/` with a live preview and viewable
source in the gallery UI.

The site is deployed as part of [tama.id](https://tama.id) at **https://tama.id/fe-pattern/**.

## Run locally

```
npm run dev      # http://localhost:8080 (zero-dependency static file server)
```

Opening `index.html` directly also works — all paths are relative.
